# ATLAS — CC0 1.0 Universal

ATLAS is an original mesh and hierarchical rigid rig made for Glide. No third-party model, textures, fonts,
animation or character artwork were used. The model data (the ATLAS joint hierarchy, mesh primitive
definitions, and expression meshes) is dedicated to the public domain under CC0 1.0 Universal.
